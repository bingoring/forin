# Pixel fonts (bundled)

forin's typography is drawn in two free Korean pixel fonts (handoff
`01_DESIGN_TOKENS`). They are loaded in `src/app/_layout.tsx` via `useFonts`; the
registration KEYS must match `src/theme/tokens.ts` exactly, because that is what
`fontFamily` resolves against.

| File | Used for | Source | License |
|---|---|---|---|
| `DungGeunMo.ttf` | headings, labels, buttons, all-caps UI | 둥근모꼴+ Fixedsys (projectnoonnu webfont, converted WOFF→TTF) | Public domain |
| `Galmuri11.ttf` | body, Korean sentences | [quiple/galmuri](https://github.com/quiple/galmuri) v2.40.4 | OFL-1.1 (`Galmuri-OFL.txt`) |
| `Galmuri11-Bold.ttf` | emphasis within body text | same | OFL-1.1 |

**Do not subset these.** Dialogue text is generated by an LLM at runtime, so any
glyph can appear; a subset would render tofu for whatever it left out. The ~15 MB
is the price of that safety.

Before these were added the app looked correct in code and wrong on screen:
every `fontFamily` silently fell back to the system face.
