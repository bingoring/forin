# 보강 저작 작업 지시 — 주제 하나 (공통)

당신은 forin(한국인 간호사가 미국 병원 영어를 배우는 앱)의 학습 콘텐츠 저작자입니다. 이미 만들어진 ICU 부서 주제
하나(주제 이름은 부르는 쪽이 알려 줍니다, 아래 `<주제>`)에 **v45 필드를 덧붙이고(보강), 기존 단어·문장을 가볍게
정리**합니다.

## 먼저 읽을 것
- `/tmp/lesson-icu-v45b/BRIEF.md` — 저작 지시서 전체. 특히 "v45 — 단어마다 더하는 회상 재료", "v45 — 상황마다 더하는
  뉘앙스 문항", "보강 모드", "보강 모드에서 허용하는 가벼운 정리 (결정 11)" 절을 꼼꼼히 읽으세요.

## 입력
- `/tmp/lesson-icu-v45b/base-<주제>.yaml` — 기존 콘텐츠(`theme` · `words` · `situations[].sentences`).
- `/tmp/lesson-icu-v45b/in-<주제>.json` — 상황별 제목·요약·첫마디·장소·역할·목표. 뉘앙스를 장면에 맞게 쓰는 데 씁니다.

## 출력
- `/tmp/lesson-icu-v45b/<주제>.yaml` — base와 모양이 같고, 단어마다 v45 필드 7개가, 상황마다 `nuance:`가 더해진 파일.
- (v44 필드를 바꿨다면) `/tmp/lesson-icu-v45b/changes-<주제>.yaml` — 지시서 결정 11 절의 형식.

## 반드시 지킬 것
1. 출력 파일을 손으로 통째로 다시 쓰지 말고, base를 읽어 새 필드만 얹는 파이썬 스크립트로 만드세요. 새로 쓰는 값은
   데이터 파일(`add_<주제>_words_1.yaml` … 처럼 **파일 이름에 주제 이름을 넣어서**)에 나눠 쓰고, 스크립트가 id와 제목으로
   맞춰 얹게 합니다. 다른 저작자가 같은 폴더를 씁니다 — 주제 이름 없는 임시 파일을 만들지 마세요.
2. 단어를 한 번에 다 쓰려 하면 출력 한도에 걸립니다. 40개 안팎으로 나눠 쓰세요.
3. **오답은 정답과 헷갈릴 만한 것, 그러나 정답으로도 맞지는 않는 것.** 품사를 맞추고, 정답의 다른 뜻을 한국어 오답에
   넣지 마세요. 음운만 닮은 일상어(`nurse`→`purse`)보다 같은 분야에서 실제로 헷갈리는 말이 좋습니다.
4. 뉘앙스의 `why`·`notes`는 **사실**이어야 합니다. 확신이 없으면 쓰지 마세요. 환자 안전에 관한 것은 특히.
5. pair는 왼쪽×오른쪽 모든 조합을 읽어 **정답이 하나로만** 맞게. context의 '어색한 장면'은 그냥 무례한 말이 아니라
   **같은 뜻인데 그 자리에 안 맞는 말**. swap은 `before[0]`+선택지+`before[2]`를 이어 읽어 문법이 맞게.
6. 가벼운 정리는 지시서 범위 안에서만, 과하지 않게(단어의 1할 안쪽이 보통). `keyPhrases` 문장의 **영어(en)·chunks는 절대 바꾸지 않습니다.** 다만 그 문장의 ko가 틀렸거나 뜻이 흐리면 ko만 고치고 변경 목록에 `{kind: sentence, …, fields: [ko]}`로 적습니다(V4는 en만 대조합니다). 이때 그 문장을 예문으로 쓰는 단어의 exKo도 같은 ko로 맞춥니다.
7. **ER 35주제 검토에서 반복해서 나온 것 — 저작 단계에서 미리 잡으세요.**
   - 오답 조각(decoyChips)으로 정답 철자를 다른 경로로 다시 만들 수 있으면 안 됩니다(heav+ily = heavi+ly). 스크립트로 확인하세요.
   - "Stay with me"를 "곁에 있어 주세요"·"곁에 계세요"로 옮기면 간호사·환자 역할이 뒤집힙니다. 환자에게는 "정신 놓지 마세요", 공황 상태 보호자에게는 "저한테 집중해 주세요".
   - "keep … down"은 "삼키다"가 아니라 "토하지 않고 넘기다".
   - 지킬 수 없는 비밀 약속("nothing leaves this room")을 가르치지 마세요. 간호사는 안전·학대·신고 의무가 있습니다.
   - 간호사 문장 목록에 환자·보호자 대사(tagline)가 섞여 있으면, keyPhrase가 아닌 경우 같은 뜻의 간호사 문장으로 바꿉니다.
   - 100.4°F(38.0°C)는 발열 기준선입니다("미열" 아님). 5분 넘는 경련은 911입니다(가정 교육).
   - 헤드워드의 ko가 태그된 문장 대부분과 맞아야 합니다(예: right가 대부분 "right now"면 "맞는; 바로"). 명사 카드가 동사 문장에, 형용사 카드가 부사 문장에 태그돼 있으면 태그를 빼거나 헤드워드를 맞춥니다.
   - 같은 id가 다른 ICU 주제에 이미 있으면(fluid, vitals, blood thinner 등) 헤드워드·ko를 맞춥니다.
   - YAML 예약어(on·off·no·yes·y·n·true·false·null)는 목록 안에서도 큰따옴표로 감쌉니다.
   - 쉬운 단어는 공통 목록에 있는 것만 반드시 뺍니다. 목록 밖의 말은 "간호사가 확실히 아는 말"일 때만 빼고, 그런 판단분은 **10개를 넘기지 마세요**(결정 11 "과하지 않게").
   - keyPhrase가 간호사 업무 범위를 벗어나면(프로토콜 없이 검사·약을 직접 오더 등) 고치지 말고 보고만 합니다.
8. **ICU는 ER과 말의 구조가 다릅니다.** 환자가 삽관·진정으로 말을 못 하는 장면이 많아 대화 상대가 보호자·동료로 옮겨 갑니다. 뉘앙스의 context·swap은 그 상대(보호자에게 / 동료에게 / 차트에)를 정확히 반영하세요.

## 검사 — 통과할 때까지
    python3 /Users/ywyeom/private/forin/server/content/tools/verify_one_theme.py icu /tmp/lesson-icu-v45b/<주제>.yaml

위반 0건, `==> 통과`까지. `[!]` 경고는 읽고 판단합니다. 정본(`server/content/nurse/...`)은 **절대 수정하지 마세요.**

## 돌려줄 말
출력 파일 경로, 단어 수, 상황 수, 뉘앙스 문항 수(종류별), 정리 결과(태그 뺀 쉬운 단어·새 단어·지운 단어·헤드워드·ko·
문장 각각 개수), 검사 결과 한 줄, 판단이 어려웠던 점. 파일 내용은 붙이지 마세요.
