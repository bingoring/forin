# core-safety-er 오답 재저작 검토 (Opus)

정본과 비교한 결과, 문장 `distractorsKo` 244개, 단어 보기 31개, 빈칸 `options` 1곳(19.4)만 바뀌었습니다. 다른 필드는 바뀌지 않았습니다.

판정 기준(이 주제에서 가장 많이 걸린 것): 같은 상황에서 꼭 해야 할 처치를 다른 처치로 바꾸는 오답은 고칩니다.
- 그런 오답은 처치를 늦추거나 빠뜨리게 합니다(검사 바꿔치기, "치운다"를 "확인한다"로 낮추기, 대피 순서 바꾸기).
- 지시서 예시처럼 상관없는 옆 단계를 말하는 오답은 둡니다.

## 저작자가 짚은 것: 판정
- **4.1 산소통** → 오답1을 고칩니다(아래 2번 항목).
  - "서류는 가득 차 있어요"는 말이 되지 않습니다.
  - 오답2 "산소통은 제가 가져갈게요"는 산소통이 가득 찼다고 거짓으로 안심시키지 않으니 둡니다.
- **13.2 동의서·부위 표시**
  - 오답1 "장갑은 준비됐어요"는 둡니다. 확인 하나를 해가 없는 다른 준비로 바꾼 것입니다.
  - 오답2 "서류는 서명됐고…"는 고칩니다(아래 9번 항목). 동의서도 서류라서 정답이 둘이 됩니다.
- **16.3 항응고제 출혈 위험** → 오답2를 고칩니다(아래 15번 항목).
  - "작은 낙상도 어지럼을…"은 출혈 위험을 어지럼으로 낮춰 말합니다. 잘못된 안심입니다.
- **10.1 억제대 확인 매시간→30분마다**: 유지합니다.
  - `every hour`가 들리고 더 엄격한 쪽이라 해가 없습니다.
  - 틀린 답으로 표시되니 기준을 잘못 가르치지도 않습니다.
