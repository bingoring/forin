## 고칠 것

1. **경증 뇌진탕 귀가교육 5.0** `Come back if you have worsening headache or vomiting.` — **안전**(저작자 재검토 요청)
   - 문제: d1 "가족에게 말해 두세요", d2 "메모해 두세요"는 응급실로 다시 오라는 지시를 지웁니다. 오답대로 하면 악화돼도 오지 않습니다.
   - 새 값: d1 `두통이나 구토가 심해지면 구급차를 부르세요.` · d2 `두통이나 어지럼이 심해지면 다시 오세요.`
     (d1은 지시 자리 come back ↔ 구급차, d2는 증상 자리 vomiting ↔ 어지럼. 둘 다 오게 만드는 말이라 안전)

2. **경증 뇌진탕 귀가교육 5.1** `Watch for confusion, drowsiness, or weakness.` — **안전**·말이 되는가(저작자 재검토 요청)
   - 문제: "사진으로 남겨 주세요 / 목록으로 만들어 주세요"는 지켜보기를 기록으로 바꾼 데다 한국어로 어색합니다(혼돈이 있는지 목록으로 만든다).
   - 새 값: d1 `혼돈, 구토, 무력감이 있는지 지켜봐 주세요.` · d2 `어지럼, 졸림, 무력감이 있는지 지켜봐 주세요.`
     (drowsiness·confusion 자리를 각각 바꿈. 바꾼 증상도 모두 경고 징후라 안전)

3. **경증 뇌진탕 귀가교육 5.3** `If the headache gets much worse, come back right away.` — **안전**(저작자 재검토 요청)
   - 문제: d1 "시간을 적어 두세요", d2 "점수를 매겨 두세요"는 다시 오라는 지시를 지웁니다.
   - 새 값: d1 `두통이 훨씬 심해지면 바로 가까운 병원에 가세요.` · d2 `구토가 훨씬 심해지면 바로 다시 오세요.`

4. **경증 뇌진탕 귀가교육 5.5** `Any seizure or trouble waking up means you need to return.` — **안전**(저작자 재검토 요청)
   - 문제: d1 "기록지를 챙겨 둬야 해요", d2 "영상을 찍어 둬야 해요"는 다시 오라는 지시를 지웁니다(발작 때 영상만 찍고 집에 있음).
   - 새 값: d1 `발작이 있거나 잘 깨어나지 못하면 119를 불러야 해요.` · d2 `발작이 있거나 말이 어눌해지면 다시 와야 해요.`

5. **경증 뇌진탕 귀가교육 5.4** `Wake him every few hours to check that he responds normally.` — 말이 되는가(저작자 재검토 요청)
   - d1 "몇 분마다 깨워서"는 더 자주 확인하는 쪽이라 안전합니다. 유지.
   - d2 "정상적으로 드시는지"는 몇 시간마다 깨워서 먹는지 본다는 말이라 어색합니다. 깨우는 행동은 남아 있어 해롭지는 않습니다.

6. **오심·구토 모니터 4.5** `Let me know right away if it gets worse.` — **안전**

   - 새 값(d2): `더 어지러우면 바로 알려주세요.` (알리는 지시는 그대로 두고 it gets worse 자리를 바꿈)
