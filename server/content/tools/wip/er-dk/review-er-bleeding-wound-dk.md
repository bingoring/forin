     (압박 유지는 그대로. 들리는 자리: lifting the gauze to check ↔ 기대앉기/팔꿈치 받치기)

## 저작자 재검토 요청 문장 판정
- 8.4: 위 4번에서 고침.
- 10.4 `…not in spurts`: 오답("냄새가 나지는 / 멍이 들지는 않아요")은 spurts 자리를 바꿨고 들립니다. 잘못된 안심이 아니므로 그대로 둡니다.
- 11.2 `looks worse than it usually is`: 오답("색이 연해요 / 냄새가 약해요")은 안심을 키우지 않고 worse 자리를 바꿨습니다. 그대로 둡니다.
  "상처가 작아요"처럼 고치면 정답과 뜻이 겹치고, "금방 멈춰요"처럼 고치면 잘못된 안심이 되므로 더 고치지 않는 편이 낫습니다.
