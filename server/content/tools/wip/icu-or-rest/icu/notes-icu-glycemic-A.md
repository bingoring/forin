# icu-glycemic A 메모 (문장 en·ko는 건드리지 않음 — 검토 판단용)

- S2 "You won't need this insulin forever, and we'll stop it as you improve." — 기존 당뇨가 있는 환자에겐 인슐린이 계속될 수 있어 지킬 수 없는 약속이 될 수 있음(nuance slider는 당뇨 병력 없음으로 한정해 둠).
- S15 "Recheck in five minutes and repeat if he's still low." — 5분은 병원 프로토콜마다 다름(D50 정맥 투여 후 재측정 간격은 보통 15분 전후). 시간 약속이 확실치 않음.
- S16 "Check his sugar now and start dextrose if he's dropping." / S18 "Start dextrose and recheck..." — 포도당 시작은 프로토콜·지시에 따른 행동으로, 간호사 단독 판단처럼 읽힘. 업무범위 확인 필요.
- S14 "I trust the lab value." — 정맥 검사실 수치를 우선한다는 일반 원칙이나, 병원 기준에 따라 다름.
- 단어 ko 한계(정리 범위 밖이라 그대로): stick(찌르다)은 문장에서 명사 "finger stick"으로 쓰임, quick은 형용사·부사(quickly) 혼재, drop(한 방울/떨어지다)·clear(분명한/가시다) 다의어. clear는 "kidneys clear insulin"(배출)·"infection clears"(가시다)·"pattern is clear"(분명)로 쓰여 ko가 문장마다 다름.
- 은행 단어 217개 중 n=1짜리 쉬운 일반어(예: between·between, safety, forever, entirely 등)가 많으나 공통 쉬운 단어 목록·판단분 상한(10)만 정리함.
