## 2 고위험약 이중확인 who=동료에게 · 투약 전 확인 ans=read the number differently ko=제 생각엔 숫자를 다르게 읽으신 것 같아요, 처방을 같이 확인할까요
   I think you [read the number differently] — can we check the order together?  -- 사람을 탓하지 않고 숫자를 같이 보자는 말이에요. 상대도 방어하지 않고 다시 볼 수 있어요.
   I think you [made a mistake] — can we check the order together?  -- 맞더라도 처음부터 잘못을 단정해 상대가 방어적으로 돼요.
   I think you [are careless] — can we check the order together?  -- 사람을 평가하는 말이라 협력이 깨져요.
   why: 이중확인은 사람을 시험하는 게 아니라 숫자를 함께 보는 절차예요. 틀렸다고 단정하기보다 같이 보자고 하세요.
## 4 낙상·손상 예방 기초 who=환자에게 · 침대 알람 설명 ans=a bit unsteady ko=침대 알람은 몸이 조금 불안정하셔서 켜 둔 거예요
   The bed alarm is here because you're [a bit unsteady].  -- 환자에게 쉬운 말이에요. 사실 그대로이고 겁을 주지 않아요.
   The bed alarm is here because you're [a fall risk].  -- 의료진이 차트에 쓰는 말이라 환자는 낙인처럼 들을 수 있어요.
   The bed alarm is here because you're [likely to fall].  -- 곧 넘어질 사람처럼 들려 불안과 위축을 키워요.
   why: 같은 안전 조치라도 환자에게는 이유를 쉬운 말로, 의료진끼리는 차트 용어로 말해요.
## 6 알람 피로 관리·맞춤화 who=동료에게 · 알람 한계 조정 ans=adjust the limits on ko=이 알람의 한계를 조정할 수 있을까요? 아무 이유 없이 계속 울려요
   Can we [adjust the limits on] this alarm? It keeps going off for nothing.  -- 환자 기저치에 맞게 한계를 조정하는 올바른 방법이에요. 병원 규정과 처방 범위 안에서 해요.
   Can we [turn off] this alarm? It keeps going off for nothing.  -- 알람을 끄면 정말 중요한 변화도 놓쳐요.
   Can we [ignore] this alarm? It keeps going off for nothing.  -- 알람 피로로 이어지는 가장 위험한 대응이에요.
   why: 성가신 알람은 끄는 게 아니라 환자에게 맞게 한계를 조정해서 해결해요.
## 11 투약 오류 예방 시스템 who=동료에게 · 펌프 경고 ans=verify the order first ko=펌프가 이 용량을 표시했으니 먼저 처방을 확인할게요
   The pump flagged this dose, so I'm going to [verify the order first].  -- 경고가 뜬 용량은 처방과 대조해 확인한 뒤에 진행해요.
   The pump flagged this dose, so I'm going to [click past it].  -- 경고를 확인 없이 넘기면 시스템이 잡은 오류를 놓쳐요.
   The pump flagged this dose, so I'm going to [wait for it to stop beeping].  -- 소리가 멈춘다고 문제가 해결되지는 않아요.
   why: 펌프 경고는 오류를 잡으려는 안전망이에요. 넘기기 전에 처방과 용량부터 확인하세요.
## 20 심각 안전사건 공개·소통 who=가족에게 · 사건 공개 ans=sorry this happened ko=이런 일이 생겨서 정말 죄송해요
   I can see how upsetting this is, and I'm [sorry this happened].  -- 일어난 일 자체에 공감하고 유감을 표해요. 가족의 감정이 아니라 사건을 인정해요.
   I can see how upsetting this is, and I'm [sorry you feel that way].  -- 가족의 감정 탓으로 돌리는 말로 들려 사과로 받아들여지지 않아요.
   I can see how upsetting this is, and I'm [sorry for the confusion].  -- 일어난 일을 혼란 정도로 줄여서 말하는 것처럼 들려요.
   why: 공감은 감정을 탓하는 말이 아니라 일어난 일을 인정하는 말로 전해요. 사건의 설명과 공개는 담당 의사가 주도해요.
