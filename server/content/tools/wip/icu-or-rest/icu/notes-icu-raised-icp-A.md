# icu-raised-icp A 메모 (문장 en·ko는 건드리지 않음 — 검토 판단용)

- "진정 중단과 신경검사 균형" 문장 0 — ko "얕춰서"는 없는 말입니다("얕게 해서/줄여서"). 단어 w-lighten의 ko만 "얕게 하다"로 바로잡았고 문장 ko는 그대로 둡니다.
- "뇌탈출 임박 위기" 문장 0 — "give hypertonic and hyperventilate now": 고장액·과호흡은 처방·지시에 따라 하는 처치인데 간호사가 단독으로 바로 하겠다는 말로 읽힙니다("per order" 단서 필요).
- "뇌탈출 임박 위기" 문장 3 — "I'm draining the EVD ... immediately": EVD 배액·수위 조절은 프로토콜·처방 범위 안에서 하는 일이라 간호사 단독 약속으로 읽히는지 확인 필요.
- "급성 뇌출혈 확대 악화" 문장 3 — "I'm reversing any anticoagulation per protocol now": 항응고 역전제 투여는 처방이 필요하고 간호사가 직접 "역전시키고 있다"고 하는 것은 업무 범위를 넘어 보일 수 있습니다.
- "ICP 상승 단계별 중재" 문장 3 — "so call for mannitol": 만니톨은 의사 처방이라 간호사가 "요청한다"는 의미라면 괜찮지만, 단독 결정처럼 읽힐 수 있어 확인 필요.
- "ICP 급상승 불응 위기" 문장 3 — ko "신경외과를 침상 곁으로 데려올게요"는 어색합니다("신경외과 의사를 바로 불러올게요").
- "EVD 시스템·영점 이해" 문장 1 — 영점 기준을 "귀"로 적었는데 병원 프로토콜마다 기준(외이도 등)이 다를 수 있어 "프로토콜에 따라" 단서가 있으면 안전합니다.
- "ICP 급상승 불응 위기" 문장 4 / "뇌사 진행 인지·검사 연계" 문장 4 — 가족 합류·장기기증 대화는 간호사 단독이 아니라 팀(의사·코디네이터) 몫이라 업무 범위 확인이 필요합니다(문장은 "준비되시면"이라 허용 가능).
