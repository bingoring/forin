# icu-nutrition B 메모 (검토 판단용 — 문장 en·ko·chunks는 고치지 않음)
- 감시·확인 문장(S2 1.x, S8 7.1·7.5, S9 8.1, S11 10.1·10.6, S20 19.2·19.6 등)은 대상 지표를 하나만 바꾼 오답이라 실패 1번에 걸릴 수 있음. 나열 항목 중 하나는 남김.
- 호출 문장(18.2 호흡치료팀·의사)은 호출 대상을 옆 팀으로 바꿈 — 검토가 판단.
- decoy 대부분은 정답 청크 하나와 같은 자리의 구로 썼으나, 시각·장소 청크 자리 일부(at lunch, last night)는 모양이 다를 수 있음.
- order 4번째 줄 몇 곳은 "Alongside/On top of all that"으로 묶음(앞 줄 가리킴).
- 위잔여량 확인 문장 0.x(주 "~할게요" 어미 반복)은 base ko 그대로.
