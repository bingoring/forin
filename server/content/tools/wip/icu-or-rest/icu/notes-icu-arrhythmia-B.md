# icu-arrhythmia B 판단 거리 (검토용)
- 응급 문장(15.x·16.x·17.x·18.x)은 용량·약·처치를 바꿀 수 없어, 오답 ko를 "같은 처치 + 부수 세부(대상·이유·조건)" 또는 "옆 단계(시간 재기·장비 정리·허락·예약)"로 썼다. 16.2(CPR 즉시 재개), 17.1(경피 페이싱 시작), 18.4(마그네슘 투여)는 정답 동사를 옆 동작으로 바꾼 오답이라 검토에서 더 안전한 안이 있으면 교체 바람.
- 2.1(농도·주입 속도 확인)은 확인 동사를 다른 동사(복사·번역)로 바꿨다. 확인 대상 값을 바꾸는 것보다 안전하다고 판단.
- 6.5·15.0 등은 "그가/남편이"처럼 주어만 바꾼 오답이 있다(처치 동사는 유지).
- 빈칸 오답은 장면과 먼 말이 일부 섞였다(주제 단위 W18 상한 때문에 보기 겹침을 피하다 보니). 약 이름·용량·경로·처치는 빈칸 정답으로 쓰지 않았다.
