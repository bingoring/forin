# icu-status-epilepticus A 메모 (문장 en·ko는 건드리지 않음 — 검토 판단용)

- 상황 "지속 SE 예후·목표 소통" 문장 3 `I won't hide anything from you.` — "아무것도 숨기지 않겠다"는 절대 약속이라, 개인정보·법적 제한이나 아직 모르는 것까지 포함해 지키기 어려울 수 있음. "솔직하게 알려 드릴게요" 정도가 안전한지 확인 필요.
- 상황 "발작 관찰·시간 기록" 문장 4 `I'll write down how long it lasts ...` 와 상황 첫마디(보호자가 시간을 물음)는 5분 기준 안내가 문장에 없음 — 문장 문제는 아니고 뉘앙스 슬라이더(5분 넘으면 도움 요청·처방된 1차 약 준비)로 보강함.
- 헤드워드가 두 뜻인 것: w-open('열린' / "Open the airway" 명령형 동사)·w-pressure(혈압 / 뇌압 문장 2건)·w-still('아직도'/'가만히')는 문장이 각 1~2건이라 그대로 둠.
- 구 단위로 바꾼 헤드워드(w-back→come back, w-effect→side effect, w-vital→vitals)는 id를 유지했고 changes에 적음.
