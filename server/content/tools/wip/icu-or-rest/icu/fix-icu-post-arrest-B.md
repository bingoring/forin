# fix-icu-post-arrest-B — B 검토 (v46 절 1~6·8, distractorsKo ①~⑥ + 되풀이 상한)

대상: `icu-post-arrest.yaml` (상황 21, 문장 127, order 21장).
전수 덤프: 문장마다 `en | ko | 오답1 | 오답2`, 빈칸 4줄, decoy, order 4줄과 인접 교환 3가지. 되풀이 상한과 길이는 스크립트로 셈.
표기: S상황.문장(0부터), D1/D2 = distractorsKo 첫째/둘째.
아래 새 오답 문구는 전부 스크립트로 다시 쟀음. 길이 규칙(1.25배 이내 또는 3자 이내, 하나는 정답 길이 이하)을 지키고, 모두 반영한 뒤에도 되풀이 상한(5회)을 넘지 않음(최대 5회: 전·의사·팀·확인). **문구를 바꿔 쓰면 다시 셀 것.**

안전 판정 기준(부르는 쪽 지시): 정답 행동의 앞·뒤 단계면 통과. 그 순간 정답 행동 대신 하는 일, 호출·확인 대상, 확인 부위, 용량·약·시점·기준을 바꾸는 것은 실패.

## 항목별 점수
1. why — 4/5. 대부분 말하는 방식의 이유를 말함. S5.4는 처방 범위를 말하지 않음(안전). 낱말 뜻만 풀이한 것이 4개, 과장 1개.
2. 빈칸 — 2/5. 보고 값(맥박 부위·리듬·시간·요일·횟수)에 빈칸을 둔 문장은 영어로 정답을 가를 수 없음(S0.4·5.3·6.5·14.4·16.4·20.5). 장면 안에서도 맞는 선택지가 약 25문장. 위험한 지시로 읽히는 선택지(탐침 부위, 수동 모드, 메페리딘 적응증, 피부 온도, MAP 기준 숫자)도 있음.
3. decoy — 4/5. 대체로 같은 분야의 다른 조각임. 반대말(`suspected`), 용량(`a lot`), 횟수(`a third`), 펌프 없는 수액(`on the pole`)이 4개.
4. distractorsKo — 2/5. 되풀이 상한(최대 5회: 안내·소변·맥박·혈당)과 길이 규칙은 통과. 그러나 **약 45문장이 확인·감시·적정 대상을 다른 지표로 바꿈**(산소화→환기·체온, 리듬→체온·동공, 동맥→체온, 칼륨→마그네슘·칼슘, 떨림→구토, 뇌파→심전도, 혈압→맥박·소변·호흡). 판단·종료 기준을 바꾼 것(S11.4·16.2·16.5·9.3·9.4·5.4)과 처치를 설명·기록으로 바꾼 것(S4.0·4.3·6.4·7.1·13.5·1.4·3.4)도 있음. 두 오답이 모두 정답보다 긴 문장 9개(아래 기타 11).
5. order — 3/5. 3·4줄을 바꿔도 말이 되는 카드 5장(S4·S6·S9·S16·S20). S7 3줄이 S7.4와 어긋남(사실 오류).
6. tag·icon — 4/5. 태그는 모두 10자 이하이고 역할을 말함. S2.4 직장 탐침에 `stetho`가 붙었지만 맞는 NbIcon이 없으니 그대로 둬도 됨.
8. 파일럿 갈래 — 3/5. 장면과 동떨어진 빈칸 오답은 일부(S5.1·7.2·8.3·9.0·17.2)에 그침. 대신 "확인 대상만 다른 지표로 바꾼 오답"이 주제 전체에 되풀이됨.

## 저작자가 물은 것

- **S19.4 D1 "조용한 방을 마련합니다" — 통과.** 고지의 앞 단계이고 "알린다"와 뜻이 겹치지 않음. 문제는 **D2 "가족을 부드럽게 안내합니다"**: 안내≈알림이라 정답이 둘 → 새 D2 "뇌사가 확인되면 알릴 사람을 먼저 정합니다."(D1이 정답보다 길어서 D2를 짧게 씀). decoy `Once brain death is suspected`는 조립하면 "의심되면 알린다"(확인 전 고지)가 됨 → `Once the chaplain arrives`.
- **재가온 속도·승압제·이송 — 이유만 바꾼 것은 통과, 기준·기간·종료 조건을 바꾼 것은 실패.**
