## 사실 오류·심각한 문제
1. **중단·앉히기 기준을 뒤집거나 바꿈(가동 중 악화의 핵심).** **3.5·6.3·5.2** `안정되면 한 단계 올려요 / 계속 진행해요 / 범위를 넓힐게요` — 멈춤 기준 문장이 진행 기준으로 뒤집혀 멈춤 기준이 사라짐. **7.3** 어지러움 → 배고픔·심심함, **3.4** 불안 → 피곤·목마름, **10.3** 출혈 위험 → 붓기·열. 빈칸 3.5 `rises`·6.3 `rise`는 실제 중단 기준(빈맥·고혈압)이라 정답 둘.
2. **낙상 위기(S17).** **17.0** `침대로/의자로 눕혀요`(쓰러지는 환자를 들어 올림) + 빈칸 `bed/chair/stretcher`, **17.2** `차트·혈압을 확인할 때까지 움직이지 마세요`(손상을 안 본 채 옮김), **17.1** `머리를 보호하려고 담요 접기·수건 가져오기`(쓰러지는 순간 손을 뗌), **17.3** 빈칸 `waist/knee/chin to toe`(머리 사정을 빼는 범위).
3. **처치 대체.** VTE: **10.2** 기계적 예방 대신 `산소·수액 치료`, **10.4** 압박기기 대신 `공기 매트리스·전기 담요`, **10.5** 약물 예방 대신 `기계적 예방·압박양말`, 1.3·1.4 예방 묶음 → `감염·낙상·호흡기 묶음`. 압력: **2.1** 분산 대신 `시트·환자복 갈기`, 4.5 팔꿈치 → `무릎·손목`. 진정: **12.2** 깊은 진정 대신 `방문·소음` 최소화.
4. **빠뜨린 확인.** **7.2** 바퀴 → `문·서랍` 잠금(저작자 질문), **16.2** 두 오답 모두 산소 증량이 빠짐(탈포화), **18.2** 산소·호출 중 하나씩 빠짐, **19.0·19.2·19.4** 라인 이탈 확인을 `꼬임·막힘·샘`으로, 0.3 9.0 9.5 4.1 8.0 8.5 13.3 1.5(확인·기록 대상 바꾸기), 6.1 다인 이동 인력 → `시간·공간`, 7.5 낙상 대비 인력 → `가족`.
