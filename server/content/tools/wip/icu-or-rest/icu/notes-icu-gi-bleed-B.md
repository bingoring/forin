# icu-gi-bleed B 메모 (검토 판단용 — 문장 en·ko는 고치지 않음)

- 18.6 "Stay with me … 저랑 계속 계세요": 환자에게 하는 말이라 "정신 놓지 마세요" 쪽이 맞음(TASK 7번 함정). ko 수정 후보.
- 8.0 "restrictive target"과 8.3 "7.2는 8보다 낮지만": 제한적 목표는 보통 Hb 7 기준인데 8.3은 8을 기준선처럼 말함. 문장 사실성 검토 필요.
- 6.3 ko "간질환으로 인한 정맥류 출혈이에요 / 위궤양이 아니라": 환자·가족에게 단정으로 들릴 수 있음(en도 단정).
- 14.6 "call report the moment we're wheels up": 관용 은어, 학습자에게 낯설 수 있음.
- distractorsKo는 정답 행동의 앞·뒤 단계("…하기 전에/…하면")나 같은 틀의 이웃 사실로 썼음. 확인·감시 문장(0.x, 3.x, 8.x, 9.x, 13.x)의 오답은 다른 지표로 바꾸지 않고 앞뒤 단계로 씀. 설명형 문장(0.1, 4.x, 6.3, 9.5, 12.x, 19.3, 20.x)은 참인 다른 설명으로 씀 — "정답 둘" 가능성은 검토가 판단.
