### A. distractorsKo — 안전(⑥) 실패 43문장
- **0.0** 정답 `그건 출혈의 징후일 수 있어서, 자세히 살펴보고 있어요.`
  - X1 `그건 출혈의 징후일 수 있어서, 보려고 난간을 올려요.` → **`그건 분명히 출혈의 징후라서, 자세히 살펴보고 있어요.`** — 난간을 올리는 것이 '자세히 살핀다' 대신 들어감(⑥ 빠뜨린 확인), 두 군데를 바꿈(①). 'can be'(가능성)를 '분명히'로 — 들리는 자리, 해 없음
- **0.4** 정답 `어지럽거나 다시 토할 것 같으면 바로 말씀해 주세요.`
  - X1 `어지러우면 혼자 일어나지 말고 그대로 누워 계세요.` → **`어지럽거나 다시 토할 것 같으면 그릇을 드릴게요.`** — '혼자 일어나지 말고 누워 계세요'는 '말씀해 주세요' 대신(알리기 빠짐), 참인 안전 수칙을 ✗로 보임, 틀이 다름
  - X2 `말씀해 주시면 바로 토할 그릇을 가져올게요.` → **`어지럽거나 다시 토할 것 같으면 바로 간호사실에 말씀해 주세요.`** — '말씀해 주시면 …'은 정답 행동(말하기)을 품음(실패 4). 알릴 곳만 바꿈(브리프 허용)
- **0.6** 정답 `다시 토할 것 같으면 알려주세요, 옆으로 눕혀드릴게요.`
  - X1 `다시 토할 것 같으면 알려주세요, 토하면 입을 닦아요.` → **`다시 토할 것 같으면 알려주세요, 석션을 켜 둘게요.`** — '토하면 입을 닦아요'는 옆으로 눕히기(흡인 예방) 대신. 함께 하는 옆 일로
- **1.4** 정답 `검사실에서 헷갈리지 않게 튜브에 이름표를 붙일게요.`
  - X1 `검사실에서 헷갈리지 않게 튜브를 따로 담을게요.` → **`검사실에서 빨리 받을 수 있게 튜브에 이름표를 붙일게요.`** — '따로 담을게요'는 이름표(검체 식별) 빠뜨림. 이름표는 두고 이유만
  - X2 `검사실로 곧장 보낼 수 있게 튜브를 봉투에 넣을게요.` → **`튜브에 이름표를 붙이기 전에 팔찌를 다시 볼게요.`** — '봉투에 넣을게요'는 이름표 빠뜨림·두 군데 바꿈. 앞 단계(이름표 붙이기 전 신원 확인 — 정답 행동은 종속절에만)
- **2.2** 정답 `동의서랑 팔찌 확인하고 이제 시작하죠.`
  - X1 `동의서랑 팔찌 가져오고 이제 시작하죠.` → **`동의서랑 팔찌 확인하고 이제 전화하죠.`** — '가져오고'는 확인을 빠뜨림(⑥). ※ ko '이제 시작하죠'가 en에 없음 — 아래 A 몫 참고

  - X1 `튜브에 이름이랑 생년월일을 직접 적을게요.` → **`팔찌에 적힌 이름이랑 생년월일을 다시 확인할게요.`** — '직접 적을게요'는 확인을 기록으로(실패 3·빠뜨린 확인). 확인할 자리만 바꿈('on the tube')
- **2.5** 정답 `검체를 보내기 전에 서명이 한 명 더 필요해요.`

  - X2 `검체를 보내기 전에 봉투가 한 장 더 필요해요.` → **`검체를 보내기 전에 서명할 사람이 한 명 더 오고 있어요.`** — '봉투가 한 장 더'도 두 번째 서명 빠뜨림

  - X1 `확인되면 준비되는 대로 바로 피를 걸어 둘게요.` → **`확인되면 준비되는 대로 바로 환자께 알릴게요.`** — '바로 피를 걸어 둘게요'는 병상 이중 확인 없이 거는 말로 읽힘

  - X1 `그 전에는 일어나지 말고 누워 계세요.` → **`그 전에 목마르면 콜벨을 눌러 주세요.`** — '일어나지 말고 누워 계세요'는 콜벨 안내를 지움(더 나빠져도 안 부름)
- **4.3** 정답 `몇 시간마다 배액 색깔을 확인해서 기록할게요.`
  - X1 `몇 시간마다 주머니를 비우면 장갑을 갈아요.` → **`한 시간마다 배액 색깔을 확인해서 기록할게요.`** — '주머니를 비우면 장갑을 갈아요'는 색 확인 대신. 간격만 더 짧게(해 없음)
- **4.5** 정답 `배액이 다시 선홍색으로 바뀌면 바로 팀에 알릴게요.`

  - X2 `팀이 오면 바로 활력징후를 새로 재 드려요.` → **`팀에 알리고 나서 배액 양도 차트에 적을게요.`** — 같음('팀이 오면' 두 번 되풀이)

  - X2 `혈액희석제를 하루에 몇 번 드시는지도 말씀해 주시겠어요?` → **`어떤 혈액희석제를 드시나요, 마지막 복용은 몇 알이었나요?`** — '하루에 몇 번'도 마지막 복용 시각을 빠뜨림. 'when'만
