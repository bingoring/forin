## 심각한 문제 (안전·사실)
1. **심정지·발관 문장의 오답 뜻이 처치를 늦춤** — S16.0·S16.2·S16.4 "흉부 압박/심폐소생술 **시간을 잴게요**·**기록을 시작할게요**", S17.1 "백마스크 환기 시간을 잴게요/기록을 시작할게요". 그 순간 해야 할 압박·환기 대신 하는 일 → 안전 실패. 같은 틀이 4문장에 되풀이돼(`시간`·`기록` 각 4회) 낱말만 보고도 걸러짐.
2. **S9.4 신경근차단제 용량** — 오답 "**열**이/**땀**이 너무 빨리 돌아오면 용량을 늘릴게요"와 빈칸 `fevers`·`sweats`·`tears`는 넣어 읽으면 "열·땀·눈물이 나면 근이완제를 올린다"는 위험한 지시. 특히 마비 환자의 땀·눈물은 **진정 부족(각성)** 신호라 근이완제가 아니라 진정을 올려야 함.
3. **S9 order 사실 오류** — "To make sure that **[deeply sedated]** stays true, I'll check the train-of-four." TOF는 신경근차단 정도를 보는 검사이지 진정 깊이를 확인하지 못함. order `why`("검사로 확인")도 같은 오류.
4. **위험한 decoy** — S9.0 `during rounds` → "he must be deeply sedated during rounds"(회진 때만 깊이 진정), S9.2 `for long` → "We never let a paralyzed patient be under-sedated for long"(잠깐은 괜찮다는 뜻).
5. **S17.4 기관내관 위치 확인 누락** — 오답 "…고정 상태를 확인", "마노미터로 커프 압력을 확인"은 capnography로 **위치 확인**하는 일을 다른 확인으로 대신함.
6. **S15.0·S15.1 급성 산소포화도 저하** — S15.0 오답1은 "막혔는지" 확인을 "새는지"로 바꿔 폐쇄 확인이 빠짐. S15.1 오답2는 FiO2 100% 대신 "혈압을 100으로 올리고".
7. **부위·약 바꾸기** — S13.1(눈→입·피부), S13.4(눈 연고→입술 연고·손 로션). 오답대로 하면 각막 보호가 빠짐.
8. **S1.0 빈칸 `actual`** — "6 mL per kilo of actual body weight"는 실제로 가장 흔한 저 TV 설정 오류(실체중 기준)라, 넣어 읽으면 틀린 설정 기준이 됨.
9. 사실 확인 요청(정본·A 판단 사항, 보고만): S17.3 윤상연골 압박은 미국 지침에서 일상적으로 권하지 않음(notes-A 6번과 같음). S12.4·S12 order "once we turn him flat again"은 일시적 저혈압이 앙와위로 돌린 뒤에야 회복된다는 인상을 줌(실제로는 대개 돌린 직후 몇 분 안에 회복).

### I. order (11)

69. **S1 order** · `why`가 "확인할 압력과 목표를 정해요"라 하나 줄에 목표(15) 없음 · why를 줄에 맞게.
