# icu-nutrition A 메모 (고치지 않고 적어 둔 것)

문장 en·ko는 바꾸지 않았다. 검토가 판단할 것:
- 장허혈 감별 징후 index 0 "Rising lactate with a tense belly makes me hold feeds": 급식 보류를 간호사 단독 판단으로 읽힐 수 있음(보류 후 의사 통보로 이어지는 문장 1이 있어 큰 문제는 아님).
- 혈당·전해질 연계 감시 index 2 "We'll adjust insulin coverage as needed": 인슐린 조정은 지시·프로토콜에 따라야 하는데 간호사가 알아서 조정하는 약속처럼 읽힘.
- 복부구획증후군 급변 위기 index 6 "I'll give more fluid while we wait for the surgeon": 수액 추가는 지시 필요한 단독 행동.
- 복부구획증후군 급변 위기 index 1·장허혈·괴사 응급 index 1 "I'm calling surgery": 수술팀 호출은 보통 의사를 통함.
- 장허혈·괴사 응급 index 4 "This looks like dead bowel, and we need surgery now": 간호사가 진단·수술 결정을 단언함.
- 장허혈·괴사 응급 index 2 "Let's support her pressure and get broad antibiotics": 항생제 시작은 의사 지시.
- 장관영양 시작·내성 관찰 index 3 "check residuals every four hours per protocol": 간격은 병원마다 다르고 위잔여량을 일상적으로 재지 않는 추세라 사실이 아닐 수 있음(문장 안에 per protocol이 있어 완충).
- 영양관 위치 확인 index 3 "I told him ... easier if he swallows": 과거형 보고 문장이라 간호사가 지금 하는 말로는 어색.
- 장관영양 불내성 관리 ko "내성"(tolerance): 약물 내성으로 읽힐 수 있어 단어 ko는 "견디는 정도"로 바꿨지만 문장 ko는 그대로 "내성".
- 영양 목표 index 2~ ko "영양액", 복부구획증후군 급변 위기 index 2 "진정과 수액 상태를 최적화": volume을 수액 상태로 옮김, 괜찮음.
- 유문후 급식 전환 index 4 "Interventional radiology will place the tube at the bedside": 삽입 주체는 병원마다 다름.
- 단어 lay의 distractorsEn `lie`는 lay/lie 혼동을 노린 의도적 오답(W13 경고 1건, 뜻이 다름).
