# icu-aki-crrt — B 검토 (v46 절 1~6·8, distractorsKo ①~⑥·되풀이 상한)

대상: `icu-aki-crrt.yaml`(A·B 합친 파일), 21상황 126문장 전수. 스크립트로 `en | ko | 오답1 | 오답2`, 빈칸 네 줄,
order 4줄(인접 교환 1↔2·2↔3·3↔4), decoy 자리 넣기를 전부 뽑아 한 줄씩 판정. **상황·문장 번호는 0부터**(저작자 메모와 같음.
메모의 "상황 6·7·13·15·16·17·18·19" = 화면의 7·8·14·16·17·18·19·20번째 상황, "7.4" = 상황 7 문장 4 `recheck in fifteen minutes`,
"17.4" = 상황 17 문장 4 `again in thirty minutes`).

안전 판정 기준(부르는 쪽 지시): 오답이 정답 행동의 **앞·뒤 단계**면 통과, 그 순간 정답 행동 **대신** 하는 일이면 실패.
호출 대상·확인 대상·확인 부위·용량·약·시점·회로 조작을 바꾸는 오답, 처치를 늦추는 decoy, 위험한 지시로 읽히는 빈칸 오답은 실패.
브리프의 "지시·처치 동사는 오답에도 남긴다"·"정답 행위에 하나를 더한 말은 정답 둘"·"처치가 하나뿐이면 참인 다른 효과·이유"도 적용.

## 저작자가 부탁한 판정

1. **처치 지시문 오답이 원인·목적·부위·시점만 바꾼 것** — 행동은 그대로 두고 **이유·목적만** 바꾼 것은 통과입니다:
   7-1(식욕·수면을 유지하려고), 9-1(시간·돈을 아끼려고), 15-1(혈압·뇌), 15-2(수분·독소), 16-2, 18-1(통증·열), 13-2 X1(오래).
   실패는 행동의 **조건·대상·시점**을 바꾼 것: 7-5·11-2(산소·혈당·땀이 떨어지면 제거 중단 — 중단 기준이 바뀜; 산소가 떨어질 때 제거를 멈추는 건
   폐부종에서는 거꾸로 된 판단), 11-0 X2(`오늘 밤에는` 최소화 = 지금 할 일을 늦춤), 11-5(`아침에`·`이번 주에` 재개 — later와 겹쳐 정답 둘이기도),
   13-4(첫/마지막 용량 전 약국 확인 — 다음 용량 전 확인이 빠짐), 13-5(식사·알람 기준 투약 시점), 15-4(`이동하는 동안`·`마무리하는 동안` 응급 카트 —
   늦춤), 18-4(`이동 중`·`검사하는 동안`만 앉히고 산소), 19-5(`열이 멎으면`·`퇴원 전에` 재평가 — 재시작 전 재평가가 빠짐).
   **부위·대상**을 바꾼 것도 실패: 5-4(구토물·침 — 대변·소변 확인이 빠짐), 16-5(라벨·알람 — 연결부 확인이 빠짐), 15-0(호흡 변화·칼슘 수치 —
   칼슘이 높다고 들으면 칼슘을 주지 않음, 가장 위험), 16-0 X2(약물을 잃었어요 — 혈액 손실이 빠짐), 16-1(새 카트·체온), 18-0(폐렴·신부전),
   19-0(열·부기 — 출혈 보고가 빠짐), 19-2(라인 교육·식이 평가 — 호출 대상), 19-3(`그녀가` 압박 — 주체, `아까` — 압박을 멈춘 것으로 읽힘).
2. **재확인 시점 오답 7-4(15분 → 10·5분), 17-4(30분 → 10·20분)** — **통과, 그대로 둡니다.** 더 이른 재확인은 환자를 다치게 하지 않고, 숫자가
   들리는 자리이며(fifteen/five/ten, thirty/twenty/ten), 숫자 되풀이 상한 안입니다. 반대로 정답보다 **늦은** 시간이었다면 실패였습니다.
3. **지연 decoy를 중립 어구로 바꾼 결과** — 다시 넣어 읽어 보니 대부분 ko와 다른 문장만 됩니다(`since lunch`·`since noon`·`in one hour`·`every other day`·
   `right away`). 남은 문제 하나: **11-0 `for tonight`** → `minimize fluid removal for tonight`(지금 → 오늘 밤으로 늦춤). 그리고 **8-5·9-2 `before we adjust`**는
   `I'll recheck the ratio/levels before we adjust`로 조립되어 조정 **뒤** 재확인을 뺀 문장이 됩니다(늦춤은 아니지만 빠뜨린 확인).
4. **메모의 임상 질문**
   - 17-1·17-5 알칼리증: **저작자 지적이 맞습니다 — 사실 오류(심각).** 시트르산 **축적**(간이 대사 못함: 총/이온화 Ca 비율 > 2.5, 이온화 Ca 저하)은
     음이온차 증가 **대사성 산증**입니다. 대사성 알칼리증은 시트르산이 과다 공급되고 **대사는 되는** 경우(과부하)의 방향이라 비율 상승과 짝이 아닙니다.
     현재 17-1 X1 `대사 산증`이 오히려 맞는 생리라 정답 둘이기도 합니다. 아래 사실 1로 고침.
   - 5-3 `works only inside the circuit`: **지적이 맞습니다.** 같은 상황이 `blood thinner`·출혈 감시(5-1·5-4·5-5)로 헤파린처럼 읽히는데, 헤파린은 저용량이어도
     전신으로 갑니다. 국소 시트르산이면 맞지만 그러면 출혈 감시 문장들의 무게가 어긋납니다. 아래 사실 2로 고침.
   - 6-3 `Blood flow is 150`: 단위가 없고, 그 문장의 why가 바로 "수치 뒤에 단위를 붙여야"라고 말해 **why와 문장이 모순**입니다. 아래 사실 3.

## 사실 오류·심각한 문제

1. **17-1·17-5·상황 17 order — 시트르산 축적을 대사성 알칼리증으로 설명(사실 오류).** 축적은 대사성 산증. 위 4번 참조.
2. **5-3 en·why·상황 5 order 2줄 — 항응고가 "회로 안에서만"(사실 오류 소지).** 헤파린 맥락에서는 틀렸고, why는 "온몸 영향이 아니다"를 사실로 단정.
3. **15-0 X2 `칼슘 수치가 위험할 정도로 높아요`** — 고칼륨혈증 응급에서 칼슘이 높다고 듣고 가면 칼슘 투여(심장 보호)를 하지 않게 됨. 상황 15·19의 보고 문장
   오답이 보고 내용(무엇이 높은지·무엇이 났는지)을 바꾼 것 전부가 같은 결.
4. **확인·처치 문장 오답의 체계적 패턴** — 확인 대상(설정값→온도, 칼슘→칼륨, 압력→온도, 라인→전선, 연결부→라벨), 기준(오더→간호 계획),
   조건(혈압→산소), 시점(뒤→전, 지금→오늘 밤)을 한 낱말 바꾼 오답이 상황 5~11·13·15~19에 몰려 있음. 브리프의 "한 군데만 바꿔라"를 지키면서
   안전한 자리를 고르지 못한 것 — 아래 고칠 것에서 앞·뒤 단계나 참인 이유로 전부 바꿈.
5. **14-4 en·상황 14 order 4줄 `increase his calories`** — CRRT가 빼는 것은 주로 아미노산·수용성 비타민·미량원소이고, 지침이 늘리라는 것은 **단백질**
   (1.5~2.5 g/kg/일)입니다. 시트르산·포도당 함유 용액은 오히려 칼로리를 **더해** 과다 공급을 조심합니다. en을 `We increase his protein…`으로(A 몫, 문장 수정 시 dK 둘도 새로).

## 고칠 것

표기: X1·X2 = `distractorsKo` 첫째·둘째. [안전] = 안전 시험 실패, [정답] = 정답 둘, [경] = 위험은 작지만 같은 결.
새 값 84개를 모두 넣은 상태로 길이(공백 뺀 1.25배·3자)와 되풀이 상한(조사를 떼고 어간 기준)을 스크립트로 다시 셈 — 길이 실패 0,
가장 많은 낱말 `간`·`혈압`·`수면`·`시간` 5회, 동사 어간 `적다`·`알리다`·`보다`·`확인하다`·`재다` 각 5회 이하(상한 안).
돌려 쓴 어간을 다른 오답에 다시 쓰면 상한을 넘으니, 수정 담당은 값을 바꿀 때 다시 세 주세요.
