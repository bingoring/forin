# core-handoff-icu B 메모
- 문장 en·ko·chunks·goal 미수정. 의심: '인계 중 확인질문' 아닌 '검사·시술 후' s3 "Repeat her chest X-ray was ordered"는 영어가 어색함(Repeat 주어) — 검토 판단.
- '급변 중 긴급 인계'의 "손이 두 사람 더"는 en "a second pair of hands"(한 사람)과 어긋남. 오답은 "세/다섯 사람"으로 씀.
- 한 단어로도 임상 항목을 못 바꾸는 문장(기준·호출·역할형)은 오답을 부득이 약하게 씀 — 검토 확인 요청:
  불안정 s0·s2(MAP 기준을 70/75로, 더 이른 호출 쪽), 임종/코드 s2(저는 약물·기록을 관리), 급변 s3·s4(호출 동사를 만나는·설명하는으로),
  불안정 s4(리듬 이름만 바꿈), 코드 s3(교대 시각), 인계 정정 s0(보고값 칼륨).
