## 사실 오류·심각한 문제
1. **처치·호출을 다른 일로 바꾼 오답(안전 ⑥) 43문장.** 가장 나쁜 것:
   - 16.0 토혈 흡인 위기에 `옆으로 눕혀 드릴게요` 대신 `석션을 가져다 둘게요`·`입 주변 피를 닦아 드릴게요`. 0.6 X1 `토하면 입을 닦아요`도 같음.
   - 18.2 X2 `기도랑 활력징후 보게 머리를 낮추죠` — 토혈 중인 환자 머리를 낮추면 흡인 위험. 오답으로도 쓰면 안 되는 처치.
   - 6.2·11.1 기도 확보 대신 `베개를 잡아 주세요`·`윤활제/체위를 먼저`(탐포네이드 전 기도 확보가 핵심 순서).
   - 11.6 정해진 식도 풍선 바람 빼기(괴사 예방) 대신 `입안 석션`·`코 주변 피부`. 11.4 무게 확인 대신 `가위를 옆에`·`줄을 잡아 둬요`.
   - 수혈 확인을 빠뜨린 것: 2.2 `동의서랑 팔찌 가져오고`, 2.3 `튜브에 직접 적을게요`(확인 → 기록), 2.5 두 번째 서명 → `라벨/봉투가 한 장 더`, 2.6 `바로 피를 걸어 둘게요`, 1.4 `튜브를 따로 담을게요`(이름표 빠짐), 11.0 풍선 테스트 빠뜨림.
   - 호출을 지우거나 기다리게 한 것: 3.4 `알람을 켤게요`, 4.5 `팀이 오면 …`(둘 다), 6.6 `옆으로 눕혀/석션해 주세요`(부르기 대신), 9.6 `의사 지시대로 수액을 열게요`·`의사가 도착하면`, 15.4 MTP에서 혈액은행 전화 대신 `쿨러를 받으러 가요`, 15.0 X2 `발동하려고 통로를 확인해요`.
   - 10.2 X2 `시술을 마치면 교정 여부를 보고 싶어요` — 교정 없이 시술하는 말로 읽힘. 11.5 X1 `관 위치를 엑스레이로 확인해요`는 **실제 안전 절차를 ✗로** 가르침.
2. **decoy 147개 전부 장소·물건 전치사구(실패 7).** `at clean gloves`·`in your son`·`on the sink`·`in a pen light`처럼 전치사부터 틀린 것도 많음. 아래 E에 전부 새 값.
3. **연결 표지만 보고 걸러지는 오답(실패 5) 44문장.** 정답에는 없는데 오답 둘에만 `-려고/-면/전엔/직전에/앞서/이전에/나면/마치면`이 있음. 주제 전체로 `~면` 68회, `려고` 29회. 아래 "저작자 문의 1".
4. **문장 사실성(A 몫·사용자 판단 — B는 고치지 않음).** 8.3 `Seven point two is below eight, but he's not actively bleeding` + order S8 1줄: GI 출혈의 제한적 수혈 기준은 Hb **7**(심혈관 질환이 있으면 8)인데, 8을 기준선처럼 말하고 그 아래인데 수혈하지 않는다고 해서 8.0 `restrictive target`과 어긋남(저작자 메모와 같은 판단). → 예: `Seven point two is above seven, and he's not actively bleeding right now.`(ko `7.2는 7보다 높고, 지금 활동성 출혈은 없어요`). 고치면 8.3 distractorsKo 둘과 빈칸(`below` → `above` 정답이면 오답 `below/near/under`)도 새로 써야 함.
   11.5 `Once both balloons are inflated, we tape the tube in place` + order S11: 실제로는 위 풍선을 부분 팽창해 **엑스레이로 위치를 확인한 뒤** 견인하고, 식도 풍선은 출혈이 계속될 때만 부풀림. 문장이 틀렸다기보다 확인 단계가 빠졌음 — 사용자 판단.

## 저작자가 판정을 부탁한 곳
### 1. 앞·뒤 단계 오답에 "…하려고/…하면/…전엔/…하기 직전에" 표지 — **걸러짐. 44문장 고칠 것**
- 스크립트(`revB2_icu-gi-bleed_shape.py`)로 세면 **정답 ko에는 표지가 없고 오답 둘에만 있는 문장이 44개**입니다(0.0~0.3, 1.0, 4.3, 5.2, 5.5, 6.0~6.2, 7.1, 7.6, 8.1, 8.2, 9.0, 9.2, 9.5, 10.0, 10.3, 10.6, 11.2, 11.3, 12.1, 12.4~12.6, 13.0, 13.5, 14.0~14.2, 15.0, 15.1, 15.6, 16.1, 17.0, 17.4, 18.0, 18.1, 19.0, 19.3, 20.2, 20.6). 셋 중 표지 없는 하나를 고르면 듣지 않고 맞습니다.
- **상한을 피해 간 흔적.** 어간 35개가 정확히 5회입니다(`보려`·`장갑`·`검체`·`가져`·`잡아`·`둘게`·`라인`·`쿨러`·`번호`·`시작`·`전엔`·`오면`…). "~전에"를 `전엔 5·직전 4·앞서 3·이전에 2·직후 1`로, "~하면"을 `오면 9·나면 6·마치면 4·끝나면 3`으로 나눠 썼습니다. 브리프의 "특정 낱말만 피하면 다른 낱말로 옮겨 간다" 그대로입니다.
- **고치는 방법(새 값에 쓴 틀).** 문장마다 오답 하나 이상을 **정답과 같은 모양(표지 없음)**으로 바꿨습니다. 쓴 틀: ① 처치가 하나뿐인 문장 — 처치는 그대로 두고 참인 다른 효과·이유(6.0 `옥트레오타이드로 문맥압을 낮추죠`, 6.1, 10.0, 19.0, 11.1, 11.6, 16.0, 17.2), ② 설명문의 해 없는 세부 하나(0.1 `방금`, 6.3 `신장병`, 9.5 `가스`, 11.3 `위궤양`, 12.4 `위`, 13.5 `수액`), ③ 더 짧은 간격·개수 하나 더처럼 그대로 해도 해 없는 값(4.3 `한 시간마다`, 8.6, 13.6, 1.0 `세 개`), ④ 알릴 사람·받는 곳(5.5 `약사`, 6.6 `담당의/신속대응팀`, 14.0·17.0 `CT팀`), ⑤ 브리프 예시처럼 뻔한 뒷정리(18.0 `수액 백은 버리지 말고 …`, 18.4). 남긴 표지 오답은 정답 행동을 종속절에 둔 앞·뒤 단계뿐입니다.
- **그대로 둔 2문장(모양 남음):** 8.2 `헤모글로빈이랑 증상을 다시 확인할게요`, 13.0 `활력징후랑 검사 수치, 새로운 출혈까지 자세히 지켜봐요` — 감시 대상·간격·방식 어느 것을 바꿔도 실패 1·3 또는 정답 둘이 되어, 안전을 위해 표지 오답을 둡니다.
- 새 값을 다 넣은 뒤 다시 세면 어간 최대 5회, 표지 모양 문장 2개입니다(`revB2_icu-gi-bleed_chk.py`).

### 2. 설명형 문장의 "참인 다른 설명" 오답 — 문장마다
| 문장 | 판정 |
|---|---|
| 0.1 | 정답 둘 아님(관·내시경은 다음 처치). 그러나 둘 다 `나오면` — 모양. X2 → `방금` |
| 4.0 | **X2 정답 둘**(`위에서 나온 걸 주머니에 모아요` = 위를 비우기). X1(관 위치)은 통과 |

| 12.0 | **X2 정답 둘**(`변 겉에 묻어 나오는 편` ≈ 아래쪽 출혈) |
| 12.3 | **X1 정답 둘**(`치핵·게실증은 선홍색 피가 나올 수도` — 정답과 같은 정보) |
| 12.1·12.4 | 정답 둘 아님, 모양 → 하나씩 교체 |

| 20.0 | **둘 다 정답 둘**(간이 응고 인자를 만들고, 정맥류가 생김 — 둘 다 참이고 "간질환 때문에 …어렵다"를 같이 설명) |

### 3. 약한 빈칸 오답
- **12.5 `mood` — 실패**(동떨어짐). `skin color`도 "안정적으로 보인다"와 어울려 정답 둘에 가까움. → `stool color / IV site / body weight`.
