# core-language-icu B 메모
- 문장 en·ko·chunks·goal 미수정. 검사 통과(위반 0, W 0).
- 한 단어로 대상·처치를 바꾸기 어려운 문장은 오답을 약하게 썼음 — 검토 확인 요청:
  - 호출 문장(0-0·9-5): 통역사를 부르는 말이라 대상·동사를 못 바꿈 → 인원("두 분")·받는 사람("그분께")·소개로만 바꿈.
  - 확인 대상이 하나뿐인 문장(2-5 통증 알림, 2-6 재방문 간격, 6-6 확인 간격, 15-0 증상): 2-5는 통증 대신 음악·조명 요청으로, 2-6·6-6은 간격을 1분/10분 같은 값으로 바꿈(같은 범위 안 값 여부 검토 필요).
  - 신호 동작 바꾸기(깜빡임↔쥐기·끄덕임)는 en에서 들리는 낱말이지만 환자가 쓸 수 있는 대체 신호라 "정답 둘" 소지가 있음(1-2, 6-0~6-3, 3-6, 4-2).
  - 5-0(약·알레르기 알려주기)는 대상을 못 바꿔 동사만 적기·보여주기로 바꿈.
  - 18-1 오답은 거짓 임상 원칙(나이·기분), 17-1 d2는 환자 뜻 대신 가족 뜻 — 오답으로 읽히지만 검토가 수위를 판단해 주세요.
- order 2-4(진정)·0-1은 "after/once" 단서로 순서를 고정했으나 가까운 두 줄(8번 문화 2·3줄)은 교환해도 어색하지 않을 수 있음.
