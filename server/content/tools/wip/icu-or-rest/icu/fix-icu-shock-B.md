# fix-icu-shock-B — B 검토 (v46 절 1~6·8, distractorsKo ①~⑥ + 되풀이 상한)

대상: `icu-shock.yaml` (상황 21, 문장 126, order 21장). `verify_one_theme.py icu` 통과.
전수 덤프: 문장마다 `en | ko | 오답1 | 오답2`, 빈칸 4줄, decoy, order 4줄 인접 교환. 되풀이 상한과 길이는 스크립트로 셈.
표기: S상황.문장(0부터), D1/D2 = distractorsKo 첫째/둘째. 고쳐 쓴 오답은 길이 규칙(1.25배 이내 또는 3자 이내, 둘 중 하나는 정답 길이 이하)을 다시 재 볼 것.

## 항목별 점수
1. why — 4/5. 대부분 말하는 방식의 이유를 말함. 사실 오류 1건(S18.3). order why가 줄 내용과 어긋난 것 2건(S5, S11).
2. 빈칸 — 2/5. 넣어 읽으면 위험한 지시가 되는 선택지 13문장(속도·용량·기준·위치·약을 바꿈). 정답이 둘인 선택지 4문장. 응급 호출 문장은 장면과 동떨어진 동사를 오답으로 씀(위험은 없고 품질이 낮음).
3. decoy — 3/5. 126개 중 92개가 장소·시간 전치사구이고, 같은 조각이 2~3번 되풀이되는 것이 27종. 보고·전달 대상이나 결정권을 바꾸는 것 3개. ko에 그대로 맞는 것 약 10개.
4. distractorsKo — 2/5. 되풀이 상한은 통과(최대 5회: 혈당·"제가", 상한에 걸림). 평상시 문장은 대체로 좋음. 그러나 **약 24문장이 화법만 바꿈**("제가 ~할게요"·"~하라고 하셨어요"·"~해 주실래요?"·"~할 수 있어요"). 바뀐 자리가 들리는 내용어가 아니고 뜻이 정답과 거의 같음. 그중 호출·확인 주체를 바꾸는 것은 안전 시험에서 실패함. 중단·보류 기준(천명음·발열), 감시 대상, 보고 대상을 바꾼 오답도 있음. 두 오답이 모두 정답보다 긴 문장이 15개(25주제 규칙 위반).
5. order — 3/5. 인접한 두 줄을 바꿔도 자연스러운 카드 5장(S4·S9·S10·S17·S19). 15단어를 넘는 줄 1개(S15). 임상 순서는 모두 맞음.
6. tag·icon — 4/5. 모두 10자 이하이고 역할을 말함. 수액·혈액에 `pill`을 씀(S2.0·2.3·7.0·10.5·16.4). NbIcon에 수액 아이콘이 없으니 그대로 둬도 됨.
8. 파일럿 갈래 — 2/5. "응급 문장은 화법만 바꿔 피하기"가 주제 전체에 되풀이됨. 장면과 동떨어진 빈칸도 응급 묶음(S19)에 몰려 있음.

## 종합
