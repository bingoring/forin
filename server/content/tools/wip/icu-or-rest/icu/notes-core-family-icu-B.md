# core-family-icu B 메모 (검토 판단 거리)
- 상황 14 원격 가족 소통: base 문장의 환자 대명사가 섞여 있음(문장 1 "his son ... talk to him", 문장 3 "in her room", 문장 4 "so he can see her face" — he는 아들, her는 환자). 고치지 않음. order 줄은 "in the room"으로 대명사를 피함.
- 상황 15·16·20(임종·급성 비탄·사별) 오답은 상태·예후를 단정하거나 거짓 희망을 주지 않게 "치료→방문", "his→her", "삶→밤"처럼 비임상 낱말·대명사만 바꿈. 검토에서 이 상황 오답을 한 번 더 봐 주세요.
- 15.5 오답 "방문으로 이걸 되돌릴 방법은…"은 방문을 탓하는 말로 읽힐 수 있는지 판단 필요.
- 상황 5·20 문장 0 `ko`는 "~합니다" 문어체(base 그대로).
