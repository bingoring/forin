# or-emergency-open B쪽 노트 (검토 판단용)
- 문장 en·ko·chunks·goal은 바꾸지 않았다. A쪽 notes(수술 방법 결정·기도 관리·약 준비는 집도의/마취과 몫)와 같은 문장들이 B에서도 그대로 오답 소재가 된다.
- 위기 문장(복강 대량 출혈·심정지·산모 대량 출혈·DIC·태아 곤란)은 정답 동사를 지키는 오답을 쓰기 어려워 일부 오답이 소견·장비·진단을 바꾼다: DIC 0 "감염이에요", 마취 유도 0 "점검됐어요", 다중 위기 0·3의 수액·산소, 손상통제 3의 비임상 장소(엘리베이터·대기실). 검토가 판단해 달라.
- 앞 단계 오답은 문장당 하나이며 "~려고" 4문장(태아 곤란 3, 심정지 0, 산모 대량 출혈 0·1), "~기 전에" 5문장.
