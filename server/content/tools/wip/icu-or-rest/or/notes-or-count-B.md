# or-count B 메모
- 문장 en·ko·chunks·goal 수정 없음.
- 계수 문장은 세는 대상·시점·소리 내어/함께·불일치 시 멈춤·찾기·영상·보고 대상 어느 것도 오답에서 바꾸지 못해, 다음 틀을 썼다. 검토에서 한 번 더 봐 주세요.
  - 처치 동사 자체가 하나뿐인 문장(0.0 초기 계수 시작, 0.3 절개 전 항상 계수, 5.0 닫기 전 봉합 계수, 16.0 닫기 전 엑스선)은 같은 틀의 앞·뒤 단계(소독·체위·흡인·조명)를 오답으로 썼다. 16.0은 "엑스선"을 다른 검사로 바꾸지 못해 이 틀이 유일했다.
  - 0.1·1.0·3.2·9.0·12.1·13.1은 정답 동사(세요)를 같은 계수 맥락의 옆 단계(꺼내요·펴요·건네요)로 바꿨다(위기 아님).
  - 위기 문장(15.x 불일치, 17.x 바늘 수색, 11.x 바늘 파손, 16.x 영상)은 정답 동사·"닫을 수 없어요"를 남기고 숫자·장소·이유·조건만 바꿨다. 15.2·15.3은 조건("계수가 맞을 때까지", "해결될 때까지")을 마취·지혈·서명·교대 같은 다른 조건으로 바꿨는데 "닫기 멈춤"은 그대로 둔 것이라 판단이 갈릴 수 있음.
  - 9.4(조각이 돌아왔는지)는 오답이 확인 대상을 손잡이·나사(조각의 일부)로 좁힌 것이라 "확인 대상만 바꾼" 쪽으로 읽힐 수 있음.
  - 9.1(포장·세척에 넣어요)·5.4(쟁반에 올려요·접어요)는 "셈에 넣어요"를 옆 동작으로 바꿈.
- 숫자 보고 문장(1.1, 2.3, 6.0, 9.2, 11.1, 11.3, 15.1, 15.4, 17.0)의 오답은 보고값 숫자만 바꾼 것.
- 빈칸: 2.0·3.1·16.x 등 "둘 다 가능한 말"을 피하려 정답 옆 후보를 같은 분야의 틀린 말로 썼다. 숫자 정답 빈칸(1.1 ten, 2.3 twelve)의 오답은 소리가 닮은 숫자.
- 오답 길이: 오답 둘 중 하나는 정답(공백 뺀 글자 수) 이하로 맞췄다(14문장은 짧은 말로 조정).
